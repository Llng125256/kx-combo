一、信号定义

  • 信号成立 = 盘中触及 EMA10−ATR14 下轨（日线级别）
  • 入场确认 = 北京 08:00 完整日K落定（UTC 日切），08:35 轮复核——进行中 bar 不参与任何判定（forming bar 隔离）
  • 已废除勿再引用：收盘位＞0.3 过滤（v1.7.41 废）、下影＞40% 主信号（v1.7.42 废，系交互伪象）、🥈主信号分级（v1.7.42 废）
  • 全信号统一 ·级 ×1.0；评分 = 1.0 × 市况层（批量日 1.2 / 常规 1.0 / 周日 ×0.5）
  • 周一桶加成暂停、环境乘子封存——⚡标签仅展示参考，不影响评分

二、仓位与风控（五条硬限）

仓位单档 6%（旧 3%/6%/8% 三档已废）。

硬限数值
并发持仓≤8 只
单票名义≤10%
总敞口≤50%
杠杆= 风险预算 ÷ 止损距离，≤5×（永不放宽）

超限截断不递补。行业分散暂缓（无行业数据源）。

三、禁入三查（买入前必查）

  1. 只买新卡：同一标的距上一信号 ≤3 个交易日才算新卡
  2. 孤星日禁入：全池当日信号 ≤2 的日子不开新仓
  3. 批量日新卡多被禁入沉底：页面标注「禁入沉底勿捡」

四、破位机（重点：两条轴，别混）

  • 破位确认 = 收盘跌破有效止损（显示止损 −0.3×ATR 死区）且过三确认（爆量 3× / 收盘瘫脚 / CCI≤−100 任一）→ 进 ⚠️ 2 日观察期
  • 观察期内任一收盘收上信号区上沿 → 复活撤警
  • 期满未收复 → 次日开盘无条件卖出

三个要点：

  1. 复活线（信号区上沿）与止损线是两条轴——收回止损线上方 ≠ 解除警报
  2. 券商挂单价（盘中触发）不参与判定，判定只认 08:00 完整日K收盘——止损别挂盘中触发单，08:00 定盘后人工执行
  3. 观察期内不补仓、不摊平

五、主流程五步（远标 → 买入 → 持有 → 各状态）

  1. 远标：每天 08:35 轮后看页面——⚠️置顶风控区（限 3 张）最优先，再看 🆕新卡与常规信号卡；卡龄标注 🆕(0-1日) / 卡龄N天(2-4) / ⏳老卡(≥5) 辅助判断
  2. 信号判定：收盘触下轨即成立，次日开盘为理论锚价 Entry
  3. 买入：按 6% 建仓，过五条风控硬限与禁入三查，任一不符即放弃；现价超锚太多 = 追高慎重
  4. 持有：挂券商保险丝死单（锚×0.8），每日收盘判定，无状态不操作
  5. 按状态操作（见第六章）
